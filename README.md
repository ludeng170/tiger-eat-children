# 老虎吃小孩

一个单文件网页版「老虎吃小孩」双人对弈小游戏（本地轮流操作，无 AI）。棋盘是泥地，棋子用大石头和小石子表示，线条像用树枝在地上画出来的。

## 在线试玩

发布到 GitHub Pages 后，打开：

```
https://<你的GitHub用户名>.github.io/tiger-eat-children/
```

也可以直接把 `index.html` 下载下来双击打开，不需要联网、不需要安装任何东西。

## 游戏规则

- 棋盘是 5×5 个交叉点（4×4 个格子），左下角为 (0,0)。
- 小孩共 20 个，开局分 4 堆、每堆 5 个，位于 (1,1)、(1,3)、(3,1)、(3,3)。
- 两只老虎在 (1,2)、(3,2)，**老虎先走**。
- 双方每次只能横竖走一格；小孩可以前后左右走。
- 小孩只有开局是叠在一起的，**分开后不能再叠**，只能走到既没有小孩也没有老虎的空点。
- 老虎跳过相邻的一个小孩、落在空点，就吃掉那个小孩（落点被占则不能吃）。
- 一回合最多吃一个小孩，也可以选择不跳、只走一格。
- **老虎**把小孩吃到只剩 6 个即获胜；**小孩**把两只老虎都堵到无路可走即获胜。

## 操作

- 点老虎（大石头）：绿点 = 走一格，红点 = 跳吃，红圈标出将被吃掉的石子。
- 点小孩（小石子堆）：绿点 = 可以移过去的空点。
- 「悔棋」回退一步，「重新开始」重开一局。

## 项目说明

- 只有一个 `index.html`，内联了全部 HTML / CSS / JavaScript，无依赖、无构建步骤。
- 棋盘用 SVG 绘制，石头的形状由固定种子的伪随机数生成，每次打开形状都一样。
- 双击 `index.html` 即可游玩，也可以放到任意静态托管服务上。
